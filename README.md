# LF Studios releases

Downloads and the update feed for LF Studios, a macOS app for screenshots,
screen recording and video editing. This repository holds no code, only the
releases: download **LF-Studios.zip** from the
[latest release](https://github.com/brightlifecreations-projects/LF-Studios-Releases/releases/latest).

Install it by hand once (the steps are in each release). After that,
LF Studios finds new versions itself (LF Studios → Check for Updates…) and
installs them when you click Install Update.
